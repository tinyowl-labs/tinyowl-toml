# MOLA Single Context Recording Template

Pre-written type configs following Museum of London Archaeology's
Single Context Recording system. Suitable for urban and rural
archaeological excavation projects using the Harris Matrix method.

## Included types

- **contexts** — with cut/deposit/masonry sub-types
- **finds** — with pottery/bone/metal sub-types  
- **samples** — environmental and dating samples

## Usage

    tinyowl template apply mola-scr
